## 🛠️ 最近项目

🌐 [HushTranslate](https://github.com/muieer/hush-translate) — 一款只在需要时出现的 macOS 翻译工具。按次数或时长开启划词翻译，用完自动关闭，减少弹窗对阅读和编辑的打扰。也支持截图与剪贴板翻译，可使用 Apple 翻译或自选云端、本地模型。

🟩 [飞书云文档日历热力图](https://github.com/muieer/feishu-artical-block-calendar-heatmap) — 一个嵌入飞书文档正文的小组件，用 GitHub 贡献日历的形式展示每天的编辑活跃度。为长期写日记、做记录提供直观反馈，让持续写作留下看得见的痕迹。
